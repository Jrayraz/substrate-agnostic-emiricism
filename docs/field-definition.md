# Field Definition: Substrate-Agnostic Empiricism

Substrate-Agnostic Empiricism is a scientific framework proposing that **patterns**, not substrates, are the fundamental units of explanation across all domains.

## Object of Study

The field studies:
1. **Microsignals** — minimal observable units of change.  
2. **Patterns** — repeated configurations of microsignals.  
3. **Cross-domain pattern equivalence** — identifying identical pattern types across different substrates.

## Methodology

1. **Observe microsignals**  
   Collect the smallest measurable fluctuations in any system.

2. **Identify repetition**  
   Determine which microsignals recur in time or space.

3. **Model patterns**  
   Build representations of repeated microsignal configurations.

4. **Compare across substrates**  
   Evaluate whether patterns in one domain match patterns in another.

5. **Classify pattern types**  
   Develop a taxonomy of universal pattern structures.

## Why Substrate-Agnostic?

Different domains use different materials:
- neurons  
- molecules  
- spacetime curvature  
- economic transactions  
- social behaviors  

But the **patterns** they produce are often identical:
- oscillations  
- cascades  
- feedback loops  
- attractors  
- symmetry breaks  
- phase transitions  
- self-similarity  

This suggests the substrate is **secondary**.  
The pattern is **primary**.

## Field Goal

To establish a unified, empirical science of:
- microsignal detection  
- pattern identification  
- pattern classification  
- cross-domain pattern mapping  
- substrate-independent modeling  

This field aims to show that **existence is pattern repetition across time and space**, regardless of medium.
