# Contributing to Substrate-Agnostic Empiricism

Thank you for your interest in contributing.  
This project is a conceptual scientific framework exploring patterns, microsignals, and substrate-independent structure.  
Contributions are welcome from any domain.

---

## How to Contribute

### 1. Add Examples
You can contribute examples of:
- microsignals in your field  
- pattern types  
- cross-domain pattern equivalence  

Place examples in `/examples` and follow the existing format.

---

### 2. Improve Definitions
If you can refine:
- microsignal categories  
- pattern taxonomy  
- field methodology  
- domain mappings  

Submit edits to `/docs`.

---

### 3. Add Models
If you have a model for:
- pattern detection  
- microsignal analysis  
- cross-domain comparison  

Add it under `/models`.

---

### 4. Keep It Substrate-Agnostic
All contributions must:
- avoid domain-specific bias  
- focus on patterns, not substrates  
- maintain empirical grounding  
- preserve universality of pattern types  

---

## Contribution Process

1. Fork the repository.  
2. Create a feature branch.  
3. Add or modify files.  
4. Submit a pull request with a clear description.  

---

## Code of Conduct

Be respectful, constructive, and collaborative.  
This project is about unifying knowledge across domains — not gatekeeping.

---

## Vision

To build a universal, empirical science of patterns detectable through repeating microsignals, independent of substrate.

Your contributions help expand that vision.
